## Creating New ADRs

Use the following template for new ADRs:

```markdown
# ADR-XXX - Title

## Status
Proposed | Accepted | Deprecated | Superseded

## Context
The context that motivated this decision.

## Decision
The decision we made.

## Consequences
The consequences of this decision, both positive and negative.
```
