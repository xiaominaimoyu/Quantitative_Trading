## 1. 背景与现状评估

### 1.1 现状摘要

当前前端为「研究控制台」风格：React 19 + TypeScript + Vite，UI 基座 AntD 6，图表 ECharts 6，数据层 React Query，路由 React Router。整体为浅色单主题，左侧固定导航（224px）+ 顶部通栏（56px，面包屑 / 环境标识 / 市场时钟 / 任务中心 / 用户菜单），内容区 1440px 上限居中。已有良好基础：语义色与行情色隔离、色觉辅助主题、等宽数字、页面状态组件（Loading/Empty/Error/Forbidden）、角色切换（研究员/审计员/管理员）。

### 1.2 核心问题

| # | 问题 | 影响 |
|---|---|---|
| P1 | 仅浅色主题，接近 AntD 默认视觉 | 量化研究长时间盯屏，图表密排时刺眼；缺乏「研究终端」的专业感与品牌识别 |
| P2 | 导航为 10 个平铺项 + 分隔线，「受控演示」「监控沙盒」等杂注内联在菜单文案里 | 信息架构没有分组层次，模型只能从策略进入，深层实体（数据集→版本→实验→运行→报告）跳转全靠多次点击 |
| P3 | 无全局搜索 / 命令面板 | 平台实体量大（策略、模型、实验、运行、报告、规则集），定位特定实体成本高 |
| P4 | 工作台是静态卡片罗列 | 不是真正的「工作区」：无实时刷新节奏、无可定制性、KPI 缺失 |
| P5 | 详情页各自为政 | 头部、指标区、标签页结构不统一，跨页面学习成本高 |
| P6 | 无暗色图表体系 | ECharts 主题临时拼装，网格/坐标轴/提示框无统一规格 |
| P7 | 桌面 1440 以下无响应式策略 | 窗口收窄或笔记本小屏体验不可控 |
| P8 | 密度不可调 | 研究场景（高密度表格盯盘）与汇报场景（宽松阅读）共用一套密度 |

### 1.3 重设计定位

一句话：**从「通用管理后台」升级为「暗色优先的专业量化研究终端」**。

- 视觉：暗色优先（Dark First）、保留浅色主题与色觉辅助，建立完整双主题令牌体系；
- 效率：命令面板（⌘K）+ 全局快捷键 + 统一详情页骨架，降低深层实体导航成本；
- 密度：紧凑/标准双密度，研究场景信息密度提升约 30%；
- 克制：不改变任何路由、API 契约与权限模型，纯表现层与交互层重设计。

## 2. 设计目标与原则

### 2.1 可验证目标（验收见 §13）

1. 双主题（暗色默认 / 浅色）+ 色觉辅助行情色，全站对比度 ≥ WCAG 2.1 AA（正文 4.5:1，大字号与图标 3:1）；
2. 任意实体（策略/模型/实验/运行/报告/数据集/规则集）从任意页面出发 ≤ 2 次键盘操作可达（命令面板）；
3. 所有详情页统一为「实体头 + KPI 带 + 标签页」骨架，页面间结构偏差为零；
4. 表格/图表密集页支持紧凑密度，首屏可见数据行数提升 ≥ 30%；
5. axe-core 扫描 0 critical / 0 serious，键盘可完成全部主流程。

### 2.2 设计原则

| 原则 | 含义 | 反例（禁止） |
|---|---|---|
| 数据优先 | 版面让位于数据，装饰元素零新增 | 大圆角卡片套卡片、营销式插画 |
| 状态即颜色 | 颜色只承担语义（状态/涨跌/层级），不做纯装饰 | 同页出现两种绿色表达不同含义 |
| 数字不跳动 | 所有数值等宽数字（tabular-nums），刷新时位数稳定 | 进度刷新导致整列宽度抖动 |
| 键盘可达 | 鼠标能做的，键盘都能做，且有快捷键 | 仅 hover 才暴露的操作无替代入口 |
| 克制反馈 | 动效只表达因果（加载/出现/引导），时长 ≤ 240ms | 页面切换花里胡哨的转场 |

## 3. 设计系统 v2（Design Tokens）

### 3.1 色彩

#### 3.1.1 主题结构

三个独立维度，两两正交，可任意组合：

```
界面主题：dark（默认） / light
行情色板：normal（红涨绿跌） / colorblind（蓝涨橙跌）
密度：    compact（默认） / comfortable
```

主题落盘到 `localStorage.qt.theme`，首次访问默认 dark + normal + compact；切换即时生效不刷新页面。

#### 3.1.2 暗色主题「终端暗」（默认）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg-page` | `#0E1117` | 页面底色 |
| `--bg-container` | `#161B26` | 卡片/表格容器 |
| `--bg-elevated` | `#1D2433` | 弹层/抽屉/悬浮 |
| `--bg-hover` | `rgba(255,255,255,0.06)` | 行 hover |
| `--border-base` | `rgba(255,255,255,0.08)` | 常规分隔线 |
| `--border-strong` | `rgba(255,255,255,0.16)` | 输入框/强调分隔 |
| `--text-primary` | `rgba(255,255,255,0.92)` | 正文/标题 |
| `--text-secondary` | `rgba(255,255,255,0.65)` | 次要信息 |
| `--text-tertiary` | `rgba(255,255,255,0.45)` | 辅助/占位 |
| `--color-primary` | `#5B7CFF` | 主操作/链接/选中（暗色下对 `#2F54EB` 提亮） |
| `--color-primary-hover` | `#7A93FF` | — |
| `--color-success` | `#3FB950` | 成功/通过 |
| `--color-warning` | `#D29922` | 警告/待处理 |
| `--color-error` | `#F85149` | 失败/阻断 |
| `--color-processing` | `#58A6FF` | 运行中/处理中 |

#### 3.1.3 浅色主题（保留并精修）

沿用现有语义：`--bg-page #F5F6F8`、`--bg-container #FFFFFF`、`--color-primary #2F54EB`、文本 `rgba(0,0,0,0.88/0.65/0.45)`。仅修正：容器投影降为 1px 边框为主、阴影为辅（与暗色体系的「容器即面板」对齐）。

#### 3.1.4 行情色（涨跌）

| 主题 | 色板 | 涨 `--market-up` | 跌 `--market-down` |
|---|---|---|---|
| dark | normal | `#FF5C5C` | `#2FBF71` |
| dark | colorblind | `#4DA3FF` | `#FF9F43` |
| light | normal | `#CF1322`（现状） | `#237804`（现状） |
| light | colorblind | `#0958D9`（现状） | `#D46B08`（现状） |

规则：行情色只允许出现在「数值涨跌、净值曲线、K 线、盈亏」语境，**禁止**用行情红/绿表达系统状态（成功/失败），反之亦然——这是现有设计的优点，重设计继续强制执行。

#### 3.1.5 状态色使用矩阵

| 状态 | 颜色 | 典型场景 |
|---|---|---|
| 运行中/排队 | processing 蓝 | 实验运行、快照构建、回测中 |
| 成功/已完成 | success 绿 | 运行完成、校验通过、服务健康 |
| 警告/待处理 | warning 橙 | 待办、风险临近阈值、数据过期 |
| 失败/阻断 | error 红 | 运行失败、风险触发、服务宕机 |
| 已取消/失效 | text-tertiary 灰 | 取消的运行、归档版本 |

### 3.2 字体与排版

| 令牌 | 值 | 用途 |
|---|---|---|
| `--font-system` | 现状中文系统字体栈（不变） | 全局正文 |
| `--font-mono` | 现状等宽栈（不变） | ID / 哈希 / 代码 / 日志 |
| `--font-size-xs` | 12px | 辅助说明、表头、标签 |
| `--font-size-sm` | 13px | 紧凑密度正文（表格默认） |
| `--font-size-md` | 14px | 标准密度正文 |
| `--font-size-lg` | 16px | 卡片标题/实体头副信息 |
| `--font-size-xl` | 20px | 页面标题 |
| `--font-size-kpi` | 28px / 600 | KPI 大数字（配 tabular-nums） |
| `--font-size-hero` | 32px / 600 | 工作台唯一主指标 |

规则：

- 所有数值一律 `font-variant-numeric: tabular-nums`（沿用 `qt-tabular`）；
- 百分比固定两位小数，金额沿用 `formatMoney` 带单位缩写，**页面内口径必须一致**；
- 实体 ID、版本哈希、时间戳一律等宽字体 + 可复制（`CopyableId` 规范见 §8.6）；
- 行高：正文 1.57，标题 1.3，KPI 数字 1.2。

### 3.3 间距、圆角、阴影、层级

- 间距：4px 基栅，刻度 `4 / 8 / 12 / 16 / 24 / 32 / 48`；紧凑密度下卡片内边距 12，标准密度 16；
- 圆角：`--radius-sm 4`（标签/输入）· `--radius-md 6`（按钮/卡片）· `--radius-lg 8`（弹层）· 禁止 > 8 的圆角出现在数据容器上；
- 阴影（暗色主题下几乎不用阴影，用边框 + 亮度分层）：
  - light：`e1 0 1px 2px rgba(0,0,0,0.04)`（卡片）· `e2 0 4px 12px rgba(0,0,0,0.08)`（弹层）；
  - dark：`e1 none + border-base` · `e2 0 8px 24px rgba(0,0,0,0.45)`；
- z-index 刻度：`sticky 100` / `header 200` / `drawer 500` / `modal 600` / `popover 700` / `toast 800` / `commandPalette 900`。

### 3.4 动效令牌

| 令牌 | 值 | 场景 |
|---|---|---|
| `--motion-fast` | 120ms | hover、开关、标签切换 |
| `--motion-base` | 180ms | 弹层出现、抽屉滑入 |
| `--motion-slow` | 240ms | 页面级骨架替换、图表初次渲染 |
| `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 默认出场缓动 |

全局尊重 `prefers-reduced-motion`：开启后所有动效降级为透明度过渡（≤ 100ms）。数字刷新不做滚动动效（保持「数字不跳动」）。

## 4. 信息架构与导航

### 4.1 导航分组（新增层次，不改路由）

```
工作区
  ├─ 工作台            /
  └─ 任务中心（入口在顶栏，导航不重复）
研究
  ├─ 数据目录          /datasets
  ├─ 策略实验室        /strategies
  ├─ 实验              /experiments
  └─ 报告              /reports
风控与治理
  ├─ 风险管理          /risk
  ├─ 审计日志          /audit
  └─ 系统健康          /system
工具
  ├─ AI 研究助手       /ai          （徽标：Beta）
  └─ 模拟盘            /paper-trading（徽标：沙盒）
```

变更要点：

1. 「受控演示」「监控沙盒」内联杂注 → 统一为右侧小号**徽标**（Beta / 沙盒），样式由令牌驱动，不再手写内联样式；
2. 模型（Models）不单列一级导航，仍从策略进入，但模型详情页加入命令面板索引与面包屑直达；
3. 侧栏分组标题（工作区/研究/风控与治理/工具）12px、text-tertiary、大写间距，不可点击；
4. 菜单项高度：紧凑密度 36px，标准 40px。

### 4.2 侧栏形态

| 形态 | 宽度 | 触发 | 说明 |
|---|---|---|---|
| 展开 | 232px | 默认 | 图标 + 文案 + 徽标 |
| 折叠（图标轨） | 64px | 点击侧栏底部折叠钮 / 快捷键 `[` | 仅图标，hover 出浮层菜单 |
| 隐藏 | 0 | 视口 < 1024px | 顶栏汉堡按钮唤出抽屉式导航 |

折叠状态记忆到 `localStorage.qt.sider`。

### 4.3 路由与面包屑

路由表**完全不变**（见 `src/router/index.tsx`）。面包屑保留路由 `handle.crumb` 机制，改动的是呈现：

- 面包屑从顶栏**下移到页面实体头内**（顶栏让给全局搜索）；
- 末级实体名可点击复制完整 ID；
- 深层页面（如运行详情）面包屑最多显示 4 级，中间折叠为 `⋯` 菜单。

### 5.2 顶栏（左→右）

| 元素 | 规格 | 说明 |
|---|---|---|
| 折叠钮 + 品牌 | 图标 28px + 「量化研究终端」15px/600 | 点击品牌回工作台 |
| 环境徽章 | Tag：`<API模式> · 无真实交易` | 沿用现状逻辑；Mock 模式为 warning 色，真实 API 为 success 色 |
| 全局搜索框 | 宽 320px（xl 屏 420px），占位符「搜索或跳转 ⌘K」 | 点击/快捷键唤出命令面板（§5.3），不是普通输入框 |
| 市场时钟 | 等宽 12px，`Asia/Shanghai`，秒级 | 沿用；hover 显示平台统一时区说明 |
| 通知中心 🔔 | 带未读角标 | 新增，见 §5.4 |
| 任务中心 ▣ | 带进行数角标 | 沿用并改版，见 §5.5 |
| 用户菜单 👤 | 头像 + 名 · 角色 | 菜单内整合：角色切换 / 界面主题 / 行情色板 / 密度 / 快捷键一览 / 退出 |

主题与密度开关从用户菜单二级项升级为**一级分组**（图标 +  segmented 三段切换），减少一次点击。

### 5.3 命令面板（新增核心组件）

快捷键：`Ctrl/⌘ + K` 全局唤出，`Esc` 关闭。结构：

```
┌──────────────────────────────────────────────┐
│ ⌕ 输入以搜索实体、页面或操作…                 │
├──────────────────────────────────────────────┤
│ 最近访问                                      │
│  ◦ exp-0042 动量因子验证 · 实验        ↵ 打开 │
│  ◦ mom-alpha-v3 · 策略版本                  │
├──────────────────────────────────────────────┤
│ 结果（输入后）                                │
│  ▸ 页面     实验 / 报告 / 风险管理 …          │
│  ▸ 实体     策略 3 · 实验 2 · 运行 5 …        │
│  ▸ 操作     新建实验 / 切换暗色 / 导出当前页  │
└──────────────────────────────────────────────┘
```

行为规格：

- 三类结果（页面 / 实体 / 操作）分组展示，模糊匹配，↑↓ 选择，↵ 执行；
- 实体搜索走现有各模块 list API（防抖 250ms，每类最多 5 条，显示「查看全部 →」跳转对应列表页并带查询参数）；
- 「操作」提供全局动作：新建实验、新建快照、切换主题/密度、复制当前链接、打开快捷键帮助；
- 最近访问保留 10 条（localStorage）；
- 空态：无结果时给出「在 数据目录 中搜索 xxx」等跨模块建议。

### 5.4 通知中心（新增）

- 铃铛 + 未读数角标（>99 显示 99+）；
- 弹层 360px，分组「今天 / 更早」，条目：级别图标 + 标题 + 相对时间 + 跳转链接；
- 来源：任务完成/失败、风险触发、快照就绪（复用现有任务与待办数据，不新增后端契约，纯前端聚合）；
- 「全部已读」与「前往任务中心」底栏。

### 5.5 任务中心（改版）

保留顶栏入口与轮询逻辑，弹层改版：

- 顶部 Tab：进行中（n）/ 已完成 / 失败；
- 进行中条目：名称 + 类型 + 进度条 + 已用时长 + ETA + 取消按钮（带二次确认）；
- 条目点击跳转沿用 `taskTarget` 映射；底部「查看全部」；
- 轮询节奏：有进行中任务 5s，空闲 30s，页面不可见时暂停（`document.visibilityState`）。

## 6. 页面骨架规范（全站统一）

### 6.1 三种页面骨架

**A. 列表页**（数据目录 / 策略 / 实验 / 报告 / 审计 / 规则集）

```
┌──────────────────────────────────────────────────────────┐
│ 页面标题 20px        副标题说明（text-secondary）          │
│                                          [主操作按钮]     │
├──────────────────────────────────────────────────────────┤
│ FilterBar：搜索框 | 状态 | 时间范围 | 更多筛选 | 视图 ▾   │
├──────────────────────────────────────────────────────────┤
│ 表格（紧凑密度，行高 40px；状态列 StatusTag；             │
│  ID 列 CopyableId；数值列右对齐 tabular）                 │
├──────────────────────────────────────────────────────────┤
│ 分页：总数 / 每页条数 / 跳页（参数写入 URL query）         │
└──────────────────────────────────────────────────────────┘
```

**B. 详情页**（策略/模型/数据集/版本/实验/运行/报告/规则集）

```
┌──────────────────────────────────────────────────────────┐
│ 面包屑（首页 / … / 实体）                                 │
│ EntityHeader：                                             │
│   标题 + StatusTag          [主操作][次操作][⋯ 更多]       │
│   meta 行：ID（可复制）· 创建者 · 创建时间 · 更新时间       │
├──────────────────────────────────────────────────────────┤
│ KpiStrip：3–6 个核心指标（KPI 大数字 + 口径 ⓘ + 涨跌）    │
├──────────────────────────────────────────────────────────┤
│ Tabs：概览 | （领域页签…） | 血缘 | 版本 | 日志/审计       │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ 页签内容（懒加载，切页签保持各自滚动位置）              │ │
│ └──────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

**C. 工作页**（新建实验 / AI 助手 / 模拟盘）——任务导向，允许打破 A/B 骨架，但头部仍用 EntityHeader 变体。

### 6.2 页面状态规范（沿用组件，统一场景）

| 状态 | 组件 | 出现场景 | 规格 |
|---|---|---|---|
| 加载 | `PageLoading` 骨架屏 | 首屏 | 骨架形状**必须匹配页面骨架类型**（列表=行骨架，详情=头+KPI+块骨架），禁止全页 spinner |
| 空 | `PageEmpty` | 无数据 | 插画禁用；图标 + 一句说明 + 主操作（如「新建实验」） |
| 错误 | `PageError` | 请求失败 | 错误摘要 + 重试按钮 + 错误详情折叠（trace id 可复制） |
| 无权限 | `PageForbidden` | 角色不足 | 说明当前角色与所需角色，提供「切换角色」快捷操作 |
| 部分失败 | `PartialResultsBanner` | 聚合接口部分成功 | 顶部横幅，列出失败数据源与重试入口 |
| 功能未启用 | `DisabledNotice` | 演示限制 | 说明 + 替代建议 |

### 6.3 刷新与实时性约定

| 数据类型 | 策略 |
|---|---|
| 进行中的任务/运行 | 轮询 5s（页面可见时），状态标签带呼吸点（processing 蓝，动效仅透明度） |
| 列表页 | 手动刷新 + 切换筛选自动刷新；不做静默轮询 |
| 工作台 | 分区独立轮询（任务 5s / 系统 30s），右上角全局「刷新节奏 ▾」可暂停 |
| 时钟/时长 | 本地秒级递增，不触发请求 |

### 7.2 数据目录 `/datasets` 与详情

**列表页（骨架 A）**：表格列 = 名称 / 类型 / 最新版本 / 快照状态（StatusTag）/ 行数 / 更新频率 / 更新时间 / 操作。筛选：类型 + 快照状态 + 关键词。「新建快照」主按钮唤起 `SnapshotCreateModal`（沿用，视觉按 §8 规范收敛）。

**数据集详情（骨架 B）**：

- KpiStrip：总行数 / 字段数 / 时间跨度 / 最新版本状态；
- Tabs：概览（元信息 + 字段 schema 表）| 数据预览（虚拟滚动表格，前 100 行）| 版本（时间线，含每版行数与 checksum 短哈希）| 血缘（LineageChain，见 §8.7）；
- 版本详情页（骨架 B 变体）：schema diff（与上一版本字段级增删改高亮）+ 统计信息（缺失率/唯一值分布小图）。

关键变更：数据预览从「占位说明」改为真实虚拟滚动表格；版本时间线增加 checksum 等宽短哈希与「基于此版本新建实验」快捷操作。

### 7.3 策略实验室 `/strategies`（含模型）

**列表页（骨架 A，双视图）**：

- 视图切换：表格 / 卡片栅格（persist 到 URL `?view=`）；
- 卡片栅格：策略名 + 类型 Tag + 最新版本状态 + 近 30 天运行迷你净值 sparkline + 运行计数；
- 表格视图：名称 / 类型 / 最新版本 / 关联模型 / 运行数 / 近 30 天胜率 / 更新时间。

**策略详情（骨架 B）**：KpiStrip = 版本数 / 运行总数 / 近 30 天胜率 / 最佳夏普（口径 ⓘ）；Tabs = 概览 | 版本（列表 + diff 入口）| 运行记录 | 血缘。

**策略版本详情（骨架 B）**：核心页签为**只读代码视图**（等宽、语法高亮、行号、顶部文件树/参数 schema 侧栏可折叠）+ 参数表 + 该版本全部运行。

**模型详情 / 模型版本详情**沿用同一骨架：模型版本突出训练指标表与特征列表，血缘页签展示「数据集版本 → 模型版本 → 策略版本 → 实验」链路。

### 7.4 实验 `/experiments`

**新建实验 `/experiments/new`（工作页 C，分步表单）**：

**实验详情（骨架 B）**：KpiStrip = run 数 / 最佳指标 / 平均耗时 / 成功率；主内容 = run 表格（状态/参数摘要/指标/耗时/操作），支持勾选 ≤ 4 个 run 后顶部浮现「对比所选 →」进入 `/compare` 并带参。

## 8. 核心组件规范

> 列出新增（★）与重大改版（◆）组件；其余现有组件仅做令牌对齐。

### 8.1 ★ CommandPalette（命令面板）
见 §5.3。技术形态：Modal 无遮罩点击关闭、置顶 z-900、输入防抖 250ms、结果分组渲染、键盘全操作。

统一详情页头部：面包屑 / 标题 + StatusTag / meta 行（等宽 ID + 复制 + 时间）/ 操作区（主操作 ≤1 个，次操作 ≤3 个，其余收进 ⋯）。吸顶变体：页面滚动超过 120px 时压缩为 48px 迷你头（标题 + 状态 + 主操作）吸顶。

### 8.5 ★ LogViewer（日志视图）

### 8.6 ◆ StatusTag / CopyableId / MarketValue
- StatusTag：色板迁移到 §3.1.5 矩阵；新增「呼吸点」变体表示进行中（仅透明度过渡）；
- CopyableId：等宽 + hover 显示复制图标 + 复制成功 1.2s 内联反馈（✓ 已复制，不弹 message）；

## 9. 数据可视化规范

### 9.1 ECharts 主题（双主题各一份，注册为 `qt-dark` / `qt-light`）

| 元素 | dark | light |
|---|---|---|
| 背景 | 透明（随容器 `--bg-container`） | 透明 |
| 网格线 | `rgba(255,255,255,0.06)` 虚线 | `rgba(0,0,0,0.06)` 虚线 |
| 坐标轴文字 | text-tertiary 11px | text-tertiary 11px |
| 提示框 | bg-elevated + border-base，等宽数值 | 白底 + e2 阴影 |
| 默认色序 | `#5B7CFF #3FB950 #D29922 #F85149 #B16EFF #39C5CF` | `#2F54EB #389E0D #D48806 #CF1322 #722ED1 #08979C` |
| 涨跌 | var(--market-up/down) | 同左 |

### 9.2 图表类型规则

- **净值/收益曲线**：折线，面积填充 8% 透明度；零轴加亮；回撤用 inverted 面积图与净值共享 x 轴上下组合；
- **K 线**：阳线空心/阴线实心（dark 下反色处理），成交量副图；
- **对比叠加**：>2 序列不开面积填充；序列 ≥ 4 强制图例分页；
- **分布/归因**：横向条形图优先（标签可读性）；
- **仪表**：仅风险概览使用，必须画阈值线；
- 所有数值轴：千分位、单位缩写（万/亿），tooltip 数值 tabular 等宽；
- 空数据：显示「暂无数据」占位而非空白坐标系；加载：图表轮廓骨架。

### 9.3 图表交互

- 时间范围快捷段（1D/1W/1M/3M/1Y/全部）右置；
- 双击图例 = 单序列隔离（solo）；
- 下载 PNG 文件名 = `页面_图表名_时间戳.png`；
- 暗色下导出的 PNG 使用浅色背景（便于贴入报告）。

## 11. 无障碍（A11y）

- 目标 WCAG 2.1 AA：正文对比度 ≥ 4.5:1，大文本/图标 ≥ 3:1（暗色令牌已按此取值）；
- 键盘：保留并扩展 skip-link；全站快捷键表（§12.4）可用 `?` 唤出说明；焦点环统一 2px `--color-primary`、offset 2px，禁止 `outline: none` 无替代；
- 语义：表格用原生 `<table>` 语义或等效 role；图表容器配 `aria-label` + 隐藏数据表（屏幕阅读器可读关键数值）；
- 涨跌/状态**不得仅靠颜色**传达：StatusTag 带图标，涨跌带 ▲▼ 或 +/- 号（色觉辅助主题下同样成立）；
- 动效：`prefers-reduced-motion` 全局降级（§3.4）；
- e2e：保留并扩充 `e2e:a11y`（axe-core），CI 0 critical 0 serious 为通过线。

## 12. 主题、密度与快捷键汇总

### 12.1 主题切换矩阵

| 维度 | 选项 | 默认 | 持久化 |
|---|---|---|---|
| 界面 | dark / light | dark | `localStorage.qt.theme.ui` |
| 行情色 | normal / colorblind | normal | `localStorage.qt.theme.market` |
| 密度 | compact / comfortable | compact | `localStorage.qt.theme.density` |

### 12.2 密度规格

| 令牌 | compact（默认） | comfortable |
|---|---|---|
| 表格行高 | 40px | 48px |
| 卡片内边距 | 12px | 16px |
| 正文字号 | 13px | 14px |
| 菜单项高 | 36px | 40px |
| 表单控件高 | 28px | 32px |

报告详情页强制 comfortable（阅读场景），其余页面跟随全局。

### 12.3 实现机制

AntD `ConfigProvider` 双 algorithm（`darkAlgorithm` / `defaultAlgorithm`）+ 自定义 token 覆盖；业务令牌全部走 CSS 变量（`:root[data-theme="dark"]` / `[data-density="compact"]`），图表主题随界面主题切换重新注册。现有 `ThemeContext` 扩展为三维度，API 向后兼容。

### 12.4 全局快捷键

| 键 | 功能 |
|---|---|
| `Ctrl/⌘ K` | 命令面板 |
| `[` | 折叠/展开侧栏 |
| `g` 然后 `d/e/s/r/k/a` | 跳转 工作台/实验/策略/报告/风险/审计 |
| `?` | 快捷键帮助 |
| `Esc` | 关闭弹层/取消跟随 |
| `t` | 切换暗色/浅色 |

页面级快捷键（如日志页 `f` 跟随模式）在对应页面帮助中列出。所有快捷键在输入框聚焦时自动失效。

## 13. 实施路线

### 阶段划分（每阶段独立可交付、可回滚）

| 阶段 | 内容 | 依赖 | 验收 |
|---|---|---|---|
| **P0 基座** | 设计令牌 v2（CSS 变量 + AntD token 覆盖）、ThemeContext 三维度、暗色 ECharts 主题、密度机制 | 无 | 全站可切换双主题双密度无白屏；对比度抽检通过 |
| **P1 框架** | App Shell v2：侧栏分组/折叠、顶栏重构、命令面板、通知中心、快捷键体系 | P0 | ⌘K 全实体可搜可达；快捷键表生效；a11y 扫描通过 |
| **P2 骨架统一** | EntityHeader / KpiStrip / FilterBar / 页面状态规范；列表页（数据集/策略/实验/报告/审计）改版 | P1 | 5 个列表页骨架 A 一致；筛选 URL 可分享 |
| **P3 详情统一** | 详情页骨架 B 全量落地（策略/模型/版本/实验/规则集）；LineageGraph | P2 | 详情页结构零偏差；血缘图可跳转 |
| **P4 重点页** | 工作台、运行详情（LogViewer/事件流）、实验对比、模拟盘、AI 助手 | P3 | §7 对应线框逐项核对通过 |
| **P5 打磨** | 响应式 sm/xs、报告阅读模式、导出 PNG、性能预算收口 | P4 | §13.2 全量验收 |

### 13.1 迁移策略

- 新组件一律新文件（`components/v2/` 过渡目录），页面逐一切换，旧组件在 P5 结束时删除；
- 令牌映射：`theme/tokens.ts` 保留导出名作为 v2 变量的别名层，页面迁移期间不炸样式；
- 每阶段完成后跑一次 `e2e` 全量 + `e2e:a11y`，回归通过才进入下一阶段。

### 13.2 量化验收标准

| 指标 | 目标 | 测量 |
|---|---|---|
| axe-core | 0 critical / 0 serious | `e2e:a11y` |
| 首屏 LCP（工作台，xl 屏） | ≤ 2.5s（Mock API） | Lighthouse |
| 主题切换 | ≤ 1 帧感知延迟，无 FOUC | 手测 + 录屏 |
| 命令面板打开到结果 | ≤ 150ms | 性能埋点 |
| 对比度 | AA 全通过 | 令牌审查脚本 |
| 键盘主流程 | 登录→找实验→看运行→导出日志 全程无鼠标 | 手测脚本 |

### 13.3 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 暗色下部分历史图表配色不可读 | 中 | P0 统一注册图表主题，P3/P4 逐页走查清单 |
| 命令面板实体搜索增加 API 压力 | 低 | 防抖 + 每类 5 条上限 + 复用 React Query 缓存 |
| 双密度引发组件高度回归 | 中 | 密度只改 5 个令牌（§12.2），组件禁用硬编码高度 |
| Mock/Real 双模式下新组件分叉 | 低 | 新组件只依赖现有 API 层类型，禁止直读 mock |
